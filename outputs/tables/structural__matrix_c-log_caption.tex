Conformal matrix of the screener C-log on the set C-log: predicted bin (rows) vs.\textbackslash{} true bin (columns), aggregated over r1--r5. Rows are normalized to 100\textbackslash{}\%. The three off-diagonal blocks (below main diagonal, above main diagonal, and both) count miscalibration in each direction. This describes the screener on the selected points alone, conditioned on being selected, not on the full pool. It answers how well the screener's predicted FOS bin matched the true one among those it admitted; it does not answer the oracle question, which is how the true bin matched the prior belief over the entire pool.
